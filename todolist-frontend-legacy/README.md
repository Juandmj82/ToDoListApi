# TodoList Frontend

Frontend de la aplicación TodoList desarrollada con HTML, CSS y JavaScript vanilla.

## 📋 Descripción

Este repositorio contiene la interfaz de usuario de la aplicación TodoList, que incluye:
- Páginas de autenticación (login/registro)
- Gestión completa de tareas
- Diseño responsive con Bootstrap 5
- Integración con API REST

## 🚀 Inicio Rápido

Para ejecutar la aplicación completa (frontend + backend), visita el repositorio principal:

**[📦 ToDoListApi - Repositorio Principal](https://github.com/Juandmj82/ToDoListApi)**

### Ejecutar solo el frontend (desarrollo)
```bash
# Clonar este repositorio
git clone https://github.com/Juandmj82/todolist-frontend-legacy.git
cd todolist-frontend-legacy

# Abrir con Live Server o servidor local
# Recomendado: usar Live Server extension en VS Code
```

## 🛠️ Tecnologías

- **HTML5**: Estructura semántica
- **CSS3**: Estilos responsive
- **JavaScript ES6+**: Lógica modular
- **Bootstrap 5**: Framework CSS
- **Font Awesome**: Iconografía
- **SweetAlert2**: Notificaciones

